# 服务台账

`inventory.yml` 是当前服务器观察结果和迁移顺序的起点，不是运行时配置。它可以被修改，但不能写入密码、Token、私钥、完整 `.env` 或数据库连接串。

每个服务至少要回答：

- 它由哪个 GitHub 仓库构建；
- 当前在哪台服务器、哪个 Compose 项目和哪个服务名运行；
- 它通过哪个域名或端口提供服务；
- 它依赖哪些数据库、缓存、队列、对象存储和证书；
- 哪些数据不能随着容器删除；
- 应用能否重建，数据能否重建；
- 清理前需要完成什么验证。

`rebuild.application` 只表示应用镜像可以重新构建，不能推导出 `rebuild.data: true`。清理动作必须先满足 `cleanup_guard`，并在目标环境完成一次恢复演练。
